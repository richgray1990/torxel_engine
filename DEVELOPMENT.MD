# Правила разработки

## Принципы
- План должен быть полным и исчерпывающим, не допускающим двойственных толкований.
- При разработке не допускается додумывать логику за разработчика во время внесения изменений
- Если в плане есть пробелы - Изменения не вносятся пока пробелы не будут устранены
- EGUI не используется, только нативные средства Bevy 0.19.1.
- Если разработчик указал "Режим планирования" — не вносим изменения, пока не будет явно указан "Режим изменения".

## Примечания
- Пункт "Зафиксировать" — обязательно выполнять после каждого этапа.
- Пункт "Пока не нужно" — отложить до отдельного обсуждения.

## ЗАВЕТЫ, ДОГМЫ и АКСИОМЫ
- Допустимо предлагать варианты при обсуждении
- Недопустимо реализовывать то, что не обсуждалось
- Ни в коем случае не запускать cargo
- Ни в коем случае не менять .gitignore
