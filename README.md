# Voxel World Engine

Высокопроизводительный воксельный движок на Rust + Bevy с симуляцией физики и торической топологией мира.

## 🎯 Цель

Создать стабильное, масштабируемое ядро симуляции, способное обрабатывать миллионы взаимодействующих вокселей без просадок FPS, избегая ошибок предыдущих прототипов на C#/Godot (GC pauses, memory fragmentation).

## 🏗️ Архитектурные принципы

- **Zero-Allocation Core**: Данные хранятся в плоских `Vec<Cell>` внутри структур `Chunk`. Никаких аллокаций в циклах симуляции.
- **ECS (Bevy)**: Логика разделена на системы. Чанки управляются через Resource (`ChunkManager`) для максимального контроля памяти.
- **Безопасность и скорость**: Активное использование `#[repr(C)]`, квантования скоростей (`i8`), битовых флагов и безопасных срезов.
- **Toroidal wrapping**: Все операции с индексами и координатами учитывают циклическую природу мира (модулярная арифметика).

## 📝 Ключевые решения

### Размер Cell: 16 байт

```rust
#[repr(C)]
pub struct Cell {
    pub material: u8,      // 1 байт
    pub flags: u8,         // 1 байт
    pub temperature: i16,  // 2 байта
    pub pressure: i16,     // 2 байта
    pub velocity_x: i8,    // 1 байт
    pub velocity_y: i8,    // 1 байт
    pub velocity_z: i8,    // 1 байт
    pub fluid_depth: u8,   // 1 байт
    _padding: [u8; 3],     // 3 байта выравнивания
}
```

Итого: 16 байт на ячейку. Для чанка 32³ = 32,768 ячеек → **512 KB на чанк**.

### Торическая топология

Мир не имеет границ — при выходе за край происходит циклический переход на противоположную сторону:

```rust
// Быстрый модуль для степеней двойки
pub const fn wrap_coord(coord: i32, size: i32) -> i32 {
    ((coord % size) + size) % size
}
```

Для размеров, являющихся степенью двойки, используется оптимизация через bitmask:

```rust
const MASK: usize = SIZE - 1;
let wrapped = coord & MASK; // эквивалентно coord % SIZE
```

### Пул чанков

Для минимизации аллокаций используется пул чанков:

```rust
pub struct ChunkManager {
    chunks: HashMap<u64, Chunk>,
    chunk_pool: Vec<Chunk>,  // Переиспользуемые чанки
}
```

При удалении чанка он не освобождается, а возвращается в пул для повторного использования.
